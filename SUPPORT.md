# Support

## Usage Questions

Use [GitHub Discussions](https://github.com/erichasinternet/apples-to-apples/discussions)
for installation help, usage questions, and ideas that are not yet actionable
bug reports.

## Bugs

Search existing issues first. If the problem has not been reported, use the
bug-report form and include the browser, extension version, retailer URL when
safe to share, expected result, and visible product evidence.

Remove account names, delivery addresses, order history, cookies, tokens, and
other private data from screenshots and logs before posting them.

## Security

Do not report vulnerabilities in public issues or discussions. Follow
[SECURITY.md](SECURITY.md) and use GitHub's private vulnerability-reporting
channel.

## Scope

Support is provided on a best-effort basis. Retailer pages change frequently,
so a URL alone may not reproduce a problem without the visible product evidence
and environment details.
